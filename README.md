#  Zepto Clone

A modern and responsive **Zepto-inspired grocery delivery website** built using **HTML5 and CSS3**. This project recreates the look and feel of a modern grocery delivery platform with a clean user interface, product sections, categories, promotional banners, and responsive design.

---

##  Features

* Modern and responsive design
* Sticky navigation bar
* Product categories section
* Special offers section
* Product cards with pricing
* Download app banner
* Professional footer
* Mobile-friendly layout
* Built using only HTML and CSS

---

##  Technologies Used

* HTML5
* CSS3
* Google Fonts (Poppins)

### Navigation Bar
